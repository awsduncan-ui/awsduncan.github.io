# SEO baseline — 23 August 2026

Search Console data through: 21 August 2026
Sitemap last read: 22 August 2026
Target query: `pubs with playgrounds`
Primary market: United Kingdom

This is the Phase 1 measurement baseline for the next SEO expansion. No website,
Search Console or deployment settings were changed while producing it.

## Main findings

- The generic target query is established but variable. Over the latest complete
  28 days it generated 138 clicks from 463 impressions at an average position of
  6.0. The latest complete seven days averaged position 5.6.
- The app-branded query remains stronger at position 2.4, but it is no longer the
  main source of generic-query clicks.
- Google has indexed the homepage, national directory and all nine regional guides.
- Only 4 of the 25 submitted pub pages are indexed. The other 21 are reported as
  `Discovered – currently not indexed` and have no recorded crawl date.
- The sitemap is healthy and contains 43 canonical URLs. Search Console last read
  it on 22 August.
- Search Console currently recognises only four external links, all pointing to the
  homepage. This is the clearest measured authority limitation.
- The national directory is indexed but weak in search performance: 2 clicks,
  101 impressions and average position 40.1 in the latest 28 days.
- `pubs with playgrounds near me` has become the largest visible opportunity:
  2,963 impressions at position 6.5, but only 2 clicks and 0.1% CTR.
- Both production audit suites pass. `/index.html` remains reachable with HTTP 200,
  but declares the root homepage as canonical. Google indexes the root and currently
  lists `/index.html` as crawled but not indexed.

## Live Google result check

Checked on 23 August using UK results, personalisation disabled and a London IP
location. Google treated the generic query as local:

- A London discovery module and local map pack appeared before standard web results.
- The Pubs With Playgrounds London guide was the second standard organic web result,
  behind `17 Pubs with Play Areas in London 2026` from What the Redhead Said.
- The Pubs With Playgrounds homepage did not appear on the first page in this
  London-localised snapshot.
- KidsPubs did not appear on the first page in this snapshot.
- The observed result is compatible with Search Console's average position of 5.6
  and with occasional user observations on page two: the query is heavily affected
  by location, result type and which Pubs With Playgrounds page Google selects.

The page immediately above the London guide has a named author, publication date,
17 individually described venues, an embedded map, nearby family attractions and
links to related county guides. KidsPubs separately claims more than 230 UK locations
and exposes a country/county/town hierarchy from its homepage. These are observed
content and architecture differences, not proof that either individual feature is a
ranking factor.

## Phase 1 conclusion

The technical foundation is functioning: the sitemap succeeds, regional guides are
indexed, canonical hosts redirect correctly and the generated site passes its audits.
The next phase should not begin with another homepage rewrite.

The measured constraints to carry into Phase 2 are:

1. Only 4 of 25 pub pages have been indexed.
2. Google recognises only four external links and none to a guide or pub page.
3. The national directory is indexed but performs poorly.
4. Generic local intent is split between the homepage, regional guides, local packs
   and other result types.
5. `near me` visibility is high but produces almost no clicks.
6. London, Greater Manchester, Bristol/Bath and Devon/Cornwall already have enough
   impressions to support evidence-led content prioritisation.

These facts provide the inputs for the Phase 2 query-to-page strategy. They do not,
by themselves, authorise content, code, deployment or Search Console changes.
